1. Titlul Proiectului
MikeFitness GYM – Sistem de Gestiune al unei Săli de Fitness

2. Descrierea Domeniului
Aplicația este un sistem de gestiune creat pentru a digitaliza și automatiza operațiunile zilnice dintr-o sală de fitness. Proiectul elimină evidența manuală și oferă un mediu centralizat pentru administrarea abonamentelor, programarea claselor și gestiunea utilizatorilor.

3. Obiective Principale
Gestiunea abonamentelor: Evidența clară a perioadelor de valabilitate și a statusului abonamentelor (activ, expirat, anulat).

Rezervări online: Permiterea înscrierii clienților la clasele de grup (Yoga, Spinning, CrossFit) în limita capacității maxime.

Controlul accesului: Restricționarea funcționalităților în funcție de rolul fiecărui utilizator.

4. Rolurile din Sistem
Admin: Administrează utilizatorii, configurează tipurile de abonamente, creează orarul claselor și vizualizează rapoarte.

Trainer (Antrenor): Vizualizează clasele alocate și lista clienților înscriși la antrenamente.

Client: Își verifică statusul abonamentului, vizualizează orarul și rezervă/anulează locuri la clase.

5. Tehnologii Utilizate
Backend: Node.js + Express.js (REST API).

Bază de Date: PostgreSQL (găzduit pe Neon Tech).
